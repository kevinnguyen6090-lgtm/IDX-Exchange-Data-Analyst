# IDX-Exchange-Data-Analyst
This repository contains data analysis work completed during my Data Analyst Internship with IDX Exchange. The project uses Python and pandas to process, validate, and explore CRMLS residential real estate from 2024-2026.

## Project Work
- Combined monthly CRMLS Sold and Listing datasets into consolidated datasets.
- Filtered the data to Residential properties.
- Exported the processed datasets for further analysis.

### Data Validation and Exploratory Analysis
- Reviewed dataset structure, column names, and data types.
- Analyzed missing values and generated a missing-value report.
- Checked for duplicate records and listing IDs.
- Validated date ranges and property types.
- Examined sold and listing price distributions using histograms.
- Investigated extreme price values and potential outliers.
